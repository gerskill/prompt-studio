# Prompt Studio

Site statique (HTML, CSS, JavaScript sans dépendance) pour créer, vérifier et ranger des prompts pour Claude.

- Assistant guidé, éditeur libre avec vérification heuristique locale, modèles, projets avec historique des versions, pack de démarrage de projet, avis enregistrés localement.
- Aucune donnée envoyée à un serveur, sauf l'option facultative « Améliorer avec Claude » avec la clé API de l'utilisateur.
- Déploiement : copier le dossier tel quel sur GitHub Pages (pas d'étape de build).

Test local : `python3 -m http.server 8793` puis ouvrir http://localhost:8793/
